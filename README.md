# Roblox-Discord-Bot
A system to send messages between services
# Requirements
## Python
### Depenancies
- Py-Cord
- ngrok
# About this bot
This bot has the capabilities to speak to Roblox and for Roblox to speak back. This is an example project, many more advanced innovations can be produced from this system. For an example an off-roblox database for saving player data.
